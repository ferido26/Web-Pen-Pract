# ACCESS CONTROL VULN
1. Vertical Priviledge Escalation- User gaining access to functionality which they are not allowed to access.
2. Horizontal Priviledge Escalation- User able to access resources belonging to other users.
## Insecure direct object reference(IDOR)
- This is an access control vuln that arises when an application uses the user supplied input to access the object directly.
- These type of vulnerability are most commonly associated with horizontal priviledge escalation, but can also arise in relation to vertical priviledge escalation.
